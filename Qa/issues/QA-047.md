## Fix
- src/components/sections/FeatureTabs.tsx: tab row is a horizontally scrollable, scrollbar-less strip (`overflow-x-auto`, no wrap, `-mr-6` so it runs to the banner edge and the third tab is clipped there; p-1 with negative margins keeps the 2px focus outline visible). Tabs `min-w-[108px] shrink-0 px-[22px]` below md (Collaborate hugs its text: 110.9 wide, text starts at +22 as in Figma), `md:w-[108px] md:px-0` and `md:overflow-visible md:p-0 md:m-0` so desktop/tablet is unchanged. role=tablist and arrow/Home/End keys unchanged; selecting a tab (click or keys) calls `scrollIntoView({block:'nearest', inline:'nearest'})` (guarded for jsdom) so the third tab scrolls fully into view.
- Banner offset `-ml-[3px] -mr-[5px]` (was `-mx-1`) so the banner sits at x=17 in the column; `pt-[40.5px] pb-[57px] gap-[25.5px]`; heading `mt-[4.5px] mb-[5.5px]`; panel `pl-6 pr-[23px]` (text 241 wide); stat card `pt-[52.25px] pb-9`, number-to-label 3, label-to-bar 10.25. md+ values untouched.
