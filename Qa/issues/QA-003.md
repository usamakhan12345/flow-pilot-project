## Fix
Confirmed by the user as a real mismatch; the left column is now top-aligned exactly as Figma encodes it (2026-10-20).
- `src/components/sections/Hero.tsx`: at xl the Container is `xl:h-[592px]` (Figma container, 4px inside the 600px hero) and the left column is `xl:self-start`; the h1 gets `xl:pt-[100px]` to reproduce the empty 100x100 "Frame 2" (91:14). Existing margins (pill mb 28, h1 mb 20, subtitle mb 32, buttons mb 36, check gap-y 8) already match Figma. The check row gap was 32px, now `md:gap-x-6` (24px) as in Figma (second check text x 285 -> 277; Figma 276). The mockup stays vertically centred in the 592px container.
- Measured at 1280, offsets from hero top (Figma / before / after): pill 4 / 56 / 4; h1 text top 160 / 111 / 160 (h1 box 60); subtitle 368 / 319 / 368; buttons 459 / 409.8 / 459; check rows 543 / 473 / 543 (text spans 624, 655 page y); mockup card x 587, y 85, 629x430 / unchanged. Hero height 600. No empty band below the checks (they end at 596).
- Mobile 375/410 layout measurements are identical before and after; 1024-1279 layout unchanged except the 8px tighter check-row gap.
