# QA-035: Mobile 375: switching to Automate or Collaborate makes the section 22px taller (layout shift)
- Status: fixed
- Severity: minor
- Viewport: mobile 375 (410 is stable)
- Section / Figma node: Interactive banner tabs / 60:73, 60:81
- Code location: src/components/sections/FeatureTabs.tsx

## Expected (Figma)
Tab content swaps without moving the content below; section height stays constant across Plan / Automate / Collaborate.

## Actual (app)
Section height is 636.5px with Plan, 658.5px with Automate and Collaborate at 375 (title "Let workflows run themselves" wraps to two lines and the description to 2 lines), pushing the stat card and all later sections down 22px. At 410 and 1280 the height is constant (636.5 / 434.5). Right image is the Plan (left) and Automate (right) state at 375.

## Screenshots
- Figma: ../screenshots/QA-035-figma.png
- App: ../screenshots/QA-035-app.png

## Suggested fix
Give the left card a min-height that fits the longest tab copy (or shorten the copy) so the banner height does not change.

## Fix
- Changed: FeatureTabs.tsx: all tab copies share one grid cell (inactive ones invisible + aria-hidden) so the card keeps the height of the tallest copy; the Collaborate title was shortened to 'Keep everyone aligned' (placeholder copy) so it fits one line at 375.
- Verified: Section height 642.5 for Plan / Automate / Collaborate at 375, 621.5 at 410, 638 at 768 and 434.5 at 1280 (also constant at 360).
