# QA-027: Mobile pricing: first card is flush with the screen edge (scrolled 20px); Figma starts at x=20
- Status: fixed
- Severity: major
- Viewport: mobile 375 and 410 (also 768)
- Section / Figma node: Pricing card row / 75:69, 2:1190
- Code location: src/components/sections/PricingPlans.tsx:105 (scroll row px-5 snap-x, cards snap-start)

## Expected (Figma)
First card (277px wide) starts at x = 20, i.e. it keeps the 20px page gutter; the next card peeks in on the right.

## Actual (app)
On load the scroller has scrollLeft = 20 (snap-start aligns the first card to the scrollport edge and ignores padding), so the Starter card is at x = 0 and touches the screen edge. Measured card x = 0 at 375 and 410, and x = 0 at 768 (scrollLeft 32). The left rounded border/shadow is clipped against the viewport.

## Screenshots
- Figma: ../screenshots/QA-027-figma.png
- App: ../screenshots/QA-027-app.png

## Suggested fix
Add scroll-pl-5 (md:scroll-pl-8, lg:scroll-pl-0) to the scroller, or stop snap aligning the first card so scrollLeft stays 0.

## Fix
- Changed: PricingPlans.tsx scroller: added scroll-pl-5 (md:scroll-pl-8, lg:scroll-pl-0) so snap-start aligns the first card to the padding edge.
- Verified: Measured: scrollLeft 0 and first card x = 20 at 375 and 410, x = 32 at 768; the next card peeks in on the right.
