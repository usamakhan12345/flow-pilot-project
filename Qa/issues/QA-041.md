# QA-041: Tablet 768/1024: hero mockup is left-aligned at 628px leaving an empty right column; banner left card narrower than stat card
- Status: fixed
- Severity: minor
- Viewport: 768 and 1024
- Section / Figma node: Hero mockup / 1:619 and interactive banner / 1:773
- Code location: src/components/sections/Hero.tsx, DashboardMockup.tsx, FeatureTabs.tsx

## Expected (Figma)
The design only defines 1280 and 375. A balanced stacked layout is expected between the breakpoints (mockup full width or centred).

## Actual (app)
At 768 the hero mockup card is 628px wide at x 32..660 (right gap 108px vs left 32px). At 1024 it is 628px at x 64..692 with a 332px empty strip on the right (the two-column hero only starts at 1280). At 768 and 1024 the interactive left card (560px) is narrower than the stat card (624px / 816px). No horizontal overflow or clipped text was found at 768 or 1024. Figma image is the 1280 hero for reference.

- Figma: ../screenshots/QA-041-figma.png

## Suggested fix
Make the mockup w-full (max 628.8px, centred) on the stacked layouts and stretch the left card with the stat card.

## Fix
- Changed: DashboardMockup.tsx: mx-auto (xl:mx-0) so the 628.8px mockup is centred on stacked layouts; FeatureTabs.tsx: the left card is only capped at 560px from xl, so it stretches with the stat card below xl.
- Verified: Measured: 768 mockup x 69.6..698.4 (centred), banner card 624 = stat card 624; 1024 mockup x 197.6, card 816 = stat 816; 1280 card 560. No horizontal overflow at 375/410/768/1024/1280.
