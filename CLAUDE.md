# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

- `npm run dev` — dev server (Turbopack) at http://localhost:3000
- `npm run build` / `npm run start` — production build / serve
- `npm run lint` — ESLint (flat config in `eslint.config.mjs`, runs `eslint` directly, not `next lint`)
- No test framework is configured yet.

## Stack

Next.js 16.4.2, React 19.3, TypeScript, Tailwind CSS v4 (CSS-first, no `tailwind.config`), App Router with `src/` directory. Import alias `@/*` maps to `src/*`.

## Important: Next.js version

`AGENTS.md` warns that this Next.js version has breaking changes from older releases. Before writing Next.js-specific code (routing, data fetching, config, caching), read the relevant guide in `node_modules/next/dist/docs/` and heed deprecation notices. Don't rely on memory of older APIs.

## Architecture

Freshly scaffolded with `create-next-app`; the app lives in `src/app/` (`layout.tsx`, `page.tsx`, `globals.css`).

- Tailwind v4 is configured in `src/app/globals.css` via `@import "tailwindcss"` and an `@theme inline` block. Design tokens (colors, fonts) go there as CSS variables, not in a JS config.
- `globals.css` still holds the scaffold defaults (white/dark `--background`/`--foreground`, Arial body font) and should be replaced with the real design tokens once the design is known.
- `AGENTS.md` is regenerated by `next dev`; keep it committed rather than deleting it.
